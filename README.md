# mongobackend

Bu proje, kullanıcı ve film verilerine erişmek için MongoDB tabanlı küçük bir REST API sunar. Kullanıcı kayıtlarını oluşturup listeleme; film kayıtlarını ve filmlere ait yorumları görüntüleme işlevlerini tek bir Express sunucusunda toplar.

Projenin amacı, istemci uygulamalarının bu verilerle HTTP üzerinden çalışabilmesini sağlayan basit bir backend örneği oluşturmaktır.
